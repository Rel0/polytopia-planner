# English UI glossary (Polytopia wiki names, common short form)

The whole UI switches from German to English. Use these terms consistently. Game names follow the Polytopia
wiki in their common short form. `js/data.js` is already translated (unit/tech/item/terrain/resource/reward names) —
read names from `PP.UNITS / PP.TECH / PP.ITEM / PP.TERRAIN / PP.RESOURCE` instead of hard-coding where possible.
